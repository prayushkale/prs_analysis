# Appendix A: Glossary

| Term | Meaning |
|------|---------|
| ATM | At The Money — strike closest to spot price |
| ITM | In The Money — option has intrinsic value |
| OTM | Out of The Money — option has only time value |
| IV | Implied Volatility — market's forecast of future volatility |
| VIX | India VIX — volatility index calculated from Nifty option prices |
| FII | Foreign Institutional Investor |
| DII | Domestic Institutional Investor |
| OI | Open Interest — total outstanding contracts |
| PCR | Put-Call Ratio — contrarian sentiment indicator |
| STT | Securities Transaction Tax — levied on every buy/sell |
| PE ratio | Price-to-Earnings ratio — valuation metric |
| Max OI | Strike with highest open interest — often acts as support/resistance |
| GIFT Nifty | Global Index for Financial Trade Nifty — Singapore-based Nifty futures (pre-2023: SGX Nifty) |
| LEAPS | Long-term Equity Anticipation Securities — options with expiry >1 year |
| Span margin | Initial margin based on worst-case loss scenario using SPAN methodology |
| Exposure margin | Additional margin during high volatility or near expiry |
| Breakeven | Strike ± premium paid/received — the price at which the trade breaks even |
| Theta | Time decay — how much option value erodes per day |
| Delta | Change in option price per 1-point move in underlying |
| Gamma | Rate of change of Delta per 1-point move |
| Vega | Sensitivity of option price to 1% change in IV |
